## 🗺️ 官方平面圖與空拍實況 100% 空間還原

本專案徹底告別憑空猜測，嚴格對標大溪國中 115 學年度官方圖資：

1. **正門迎賓大道與中央銅像廣場**：
   - 南側校門入口設有警衛室與「現在位置（You Are Here）」立牌。
   - 進入前庭可見標誌性的**中央迎賓銅像景觀台**。
2. **學生活動中心（西南側）**：
   - 挑高室內綜合球場、大禮堂舞台、消防機房。
   - 完整還原空拍實況之**粉紅磚色外牆與右側圓柱雙塔（樓梯井）**。
3. **操場及綜合運動場（西北側）**：
   - 200m 深碳黑耐磨 PU 跑道，內圈草坪右側置入**排球場**。
   - 司令台還原**鮮紅雙坡金屬斜屋頂**與**飄揚之國旗桿**。
4. **戶外籃球場、蘭亭與訓平池（北側景觀）**：
   - 操場東北側建置**大型橘色戶外籃球場與排球場**（配備標準籃球框組）。
   - 操場北側綠意步道設置**蘭亭（紅色六角涼亭）**與**生態景觀訓平池**。
5. **行政大樓（雙棟通廊前後相連）**：
   - **前棟**：1F 八九年級導師室、2F 校長室/會客室/教務處、3F 語言教室。
   - **後棟**：1F 健康中心/專任辦公室、2F 總務處/人事室/會計室、3F 教師研習中心。
6. **教學大樓群（八、九年級三排平行棟舍）**：
   - **八年級前棟**：1F 非營利幼兒園、2F 807/801/802/803、3F 806/808/桌遊教室。
   - **八年級中棟**：1F 木藝教室/804/809、2F 805/專科教室、3F 表演教室。
   - **九年級後棟**：1F 908/905/903、2F 907/904/902、3F 906/901。
   - 每棟樓宇之間均建置實體**連通廊（Breezeway）**。
7. **東側縱向專科大樓群**：
   - **科技館**（1F 視聽/生科、2F 理化第一/第二實驗室、電腦教室）。
   - **綜合大樓**（1F 餐飲烹飪/校史室/圖書室 Library、2F 大電腦/資訊機房）。
   - **藝術館**（1F 樂活、2F/3F 音樂、4F 美術教室）。
   - **七年級新大樓**（1F 701/709體育班/704/708、2F 702/703、3F 706/707/數學研究室）。

## 🌟 來賓導覽關鍵功能

* **🚶‍♂️ 一鍵自動帶路（Auto-Guide）**：點選任一處室或教室，點擊「自動帶路」，3D 學生角色將自動沿著 3D 發光動線跨穿堂、爬樓梯帶您走到門口！
* **⌨️ / 📱 雙模移動控制**：電腦支援鍵盤 `W/A/S/D`（Shift 衝刺），手機與觸控螢幕具備右下角方向控制盤（▲ ◀ ▶ ▼）。
* **🗺️ 官方平面圖對照**：點擊「平面圖」或按鍵盤 `M`，即時彈出 115 官方校園平面對照圖。
* **🏢 1F ~ 4F 樓層剖切**：右側可隨時切換單層透視，隔間一目了然。
